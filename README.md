# Тренажёр звука [Р]

Статический интерактивный сайт для автоматизации твёрдого звука [Р] у школьников 8–10 лет.

## Запуск

Откройте `index.html` напрямую или запустите любой статический сервер, например:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Сборка и серверная часть не требуются. Прогресс хранится в `localStorage` браузера.

## Добавление занятий

Данные первого занятия находятся в `js/lessons/lesson-1.js`. Новые занятия можно добавлять отдельными файлами данных и карточками в массив интерфейса, сохраняя hash-навигацию и относительные пути к ресурсам.
